# 山海 · SHAN HAI

一座庭，六道门。每一道门里都藏着一个问题。

以 Canvas 2D 现场绘制的中国神话沉浸式网站——山、云、楼阁、浪、火，全部由代码生成，
没有一张贴图、没有一个模型。页面与交互参考 MYTHOS（希腊神庙）的版式与运镜，建筑换成了
五层重檐的楼阁，神话换成了六则中国故事。

## 打开方式

- 直接双击 `index.html`（纯静态，无需构建）；
- 或在目录内起一个静态服务：`python -m http.server 8123 --bind 127.0.0.1`，
  然后访问 <http://127.0.0.1:8123/index.html>。

字体会在联网时自动加载 Cormorant Garamond / Jost / Noto Serif SC，断网时回落到系统宋体与几何无衬线。

## 怎么玩

- 主页：移动指针，光会在六座山门之间游走；点门上的名字进入。
- 每道门都是一个"用双手提问的装置"：

| 门 | 操作 | 反馈 |
| --- | --- | --- |
| 愚公移山 | 点击山脚搬土 | 山形几乎不变，计数在涨 |
| 后羿射日 | 按住拖动瞄准，松手放箭 | 十日逐个熄灭，只剩一日 |
| 夸父逐日 | 按住奔跑 | 影子越来越长，最后倒下 |
| 女娲补天 | 拖动五色石入裂缝 | 缝一点一点合上 |
| 大禹治水 | 按住疏导 | 水位回落，河道成形 |
| 精卫填海 | 点击投石 | 海面依旧，石头落进浪里 |

- `Esc` 回到庭中，`R` 重置当前这一幕，右上角可开关声音（风声 + 低频 drone + 音效全部由 WebAudio 合成）。

## 结构

```
index.html          页面骨架：顶栏、主标题、六门标签、铭牌、仪式面板、关于抽屉、开场
css/style.css       版式与材质：暖灰石色、青铜描边、grain 噪点、暗角
js/paint.js         绘画基元：天空、日、山、雾、屋顶、台基、人物、弓手、鸟、石、粒子
js/scenes.js        七幕场景：庭（楼阁 + 云海）与六道门，含每幕的交互与状态
js/app.js           路由、循环、视差、铭牌同步、索引浮层、关于抽屉、WebAudio、开场进度
shots/              各轮验收截图
```

## 一点说明

所有画面在运行时逐帧生成：山的轮廓由带噪声的高度曲线采样而成，瓦垄是循环画的竖条，
云海是分层的高斯雾斑，水纹是正弦偏移的横线。想换配色，只改 `css/style.css` 顶部的
`:root` 变量与 `js/paint.js` 里的几个色板即可。
